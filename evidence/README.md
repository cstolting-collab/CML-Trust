# Public Evidence

This directory contains bounded, reviewable evidence associated with public CML Trust research.

Its purpose is reproducibility. Each evidence bundle should identify the tested question, preserved artifacts, observed result, relevant identifiers, limitations, and whether independent replication occurred.

## Evidence standard

A public evidence bundle should state:

- the research question;
- exact public artifacts used;
- expected evaluation path;
- observed result;
- relevant hashes or immutable identifiers;
- known limitations;
- replication status.

Implementation facts and interpretation should remain separate.

## Interpretation rule

A reproducible artifact can support a statement about that artifact and the tested implementation path. It does not by itself establish general correctness, hidden model behavior, trusted chronology, causal influence on a generator, statistical validity, or equivalence to a formal proof system.
